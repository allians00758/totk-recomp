### Рекомпилятор

- **Переходы `adr` + `br` внутри функции.** `br`, который не является таблицей переходов, получает в качестве целей
  адреса, которые функция сама вычисляет через `adr` / `adrp+add`. Нужно распаковщику zstd в TOTK.
- **Эксклюзивные пары `LDXP`/`LDAXP`/`STXP`/`STLXP`.** 64-битная пара — один 128-битный эксклюзивный доступ
  (`cmpxchg16b`, встраивается на x86-64-v2 и выше), 32-битная — один 64-битный. Тест: `tools/test_excl_pair.c`.

### Графика

- **Заголовок NVN у вычислительных шейдеров** (`0x12345679`): код начинается с 0x80.
- **Новые инструкции Maxwell:** `RED` (атомарные add/min/max/and/or/xor над глобальной памятью, u32 и s32),
  `VOTE` (all/any/eq и маска через расширения подгрупп), `LEA.HI` с базой из константного буфера, `VMNMX` с 32-битными
  операндами и вторым min/max.
- **Диагностика:** для непереведённого шейдера лог пишет пул памяти, тип памяти и первые слова кода;
  `SAVAGEWIND_LOG_POOLS=1` — все пулы памяти игры.

### Рантайм

- **Сервис `hwopus`** (аппаратный декодер Opus): TOTK декодирует им голоса и звуки, в BotW его не было. Декодирует
  встроенный в FFmpeg декодер Opus в 16-битные отсчёты; нераспознанный пакет даёт тишину нужной длины. Многопоточные
  (multistream) декодеры пока не поддержаны.
- **`ISaveDataInfoReader`** (`fsp-srv` 60, 61, 62, 68): перечисление сохранений возвращает пустой список. TOTK при
  запуске перечисляет свои кэш-хранилища; без объекта-читателя она вызывала метод у нулевого указателя.
- **Код игры без адресов BotW** (`gen.py --no-sites`): рантайм загружает его, а всё, что работает через объекты
  BotW (меню настроек, пауза и темп кадров, строка версии на титульном экране, перенаправление голосов), выключено.
- **Виртуальная память SDK.** `GetInfo(16)` возвращает system resource из `main.npdm` (у TOTK 24 МБ), поэтому
  включается `nn::os::AllocateAddressRegion`. `MapPhysicalMemory`/`UnmapPhysicalMemory` работают с любыми
  диапазонами страниц и, как ядро Switch, отображают память только в ещё не отображённые страницы (уже
  отображённые сохраняют данные). На Linux снятая память возвращается системе. До 8192 областей памяти (было 1024).

### Сборка

- **zig на SteamOS:** явная цель `-target x86_64-linux-gnu.2.35`, чтобы zig брал свои заголовки glibc (на SteamOS их
  нет: `LibCStdLibHeaderNotFound`).
- **`make gamelib-id` и `tools/link_gamelib.sh`:** сборка `swgame.so` из объектов, скомпилированных вне `make`
  (например zig'ом на Steam Deck), с идентификатором, который принимает рантайм.
