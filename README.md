# TOTK Recomp

**TOTK Recomp** — статическая рекомпиляция *The Legend of Zelda: Tears of the Kingdom* (Nintendo Switch) в
нативное приложение для Linux (x86-64, включая Steam Deck). Код игры переводится из машинного кода ARM64 в C и
компилируется на машине игрока из его собственной копии игры. Цель — сохранить купленную игру и играть в неё на ПК
без эмулятора.

> [!WARNING]
> **Ранняя стадия: игра пока не запускается до картинки.** Весь код TOTK уже переводится в C и компилируется,
> рантайм загружает его, проходит инициализацию SDK и игры, поднимает графику NVN поверх Vulkan и читает файлы
> игры. Сейчас идёт этап «запуск → лог → исправление»: каждая остановка в логе показывает, что ещё нужно
> реализовать. Прогресс — в [CHANGELOG.md](CHANGELOG.md), технические подробности — в [docs/TOTK.md](docs/TOTK.md).

> [!IMPORTANT]
> **Проект сделан с помощью ИИ.** Код, анализ и документация пишутся ИИ (Claude от Anthropic) под руководством
> человека, который тестирует всё на своей копии игры. Если вы не доверяете коду, написанному ИИ, — просто не
> используйте проект.

> [!NOTE]
> **Файлов игры здесь нет и не будет.** Нужна ваша собственная, законно купленная копия TOTK, снятая с **вашей**
> консоли. Проект не содержит и не распространяет файлы игры, ключи, прошивку, инструменты для дампа или
> расшифровки и инструкции по их получению. Он только читает уже извлечённые вами файлы. Сгенерированный код и
> собранная библиотека игры — производные от вашей копии: ими нельзя делиться.

## Основа

TOTK Recomp построен на [Savage Wind Recomp](https://github.com/Revivedx/SavageWindRecomp) (рекомпиляция
*Breath of the Wild*), который сам основан на [LAS Recomp](https://github.com/peiikai/LASRecomp). Движок TOTK
вырос из движка BotW, поэтому от Savage Wind взято почти всё: рекомпилятор, замена ОС Switch, графика NVN на Vulkan,
переводчик шейдеров Maxwell. Вся история Savage Wind сохранена в git, а новые исправления оттуда можно забирать:
`git remote add upstream https://github.com/Revivedx/SavageWindRecomp`.

Внутри программа пока называется `savagewind` (бинарник, папка данных `~/.local/share/savagewind`, переменные
окружения `SAVAGEWIND_*`). Это переименуется, когда игра дойдёт до первого кадра.

## Что нужно

- *The Legend of Zelda: Tears of the Kingdom* для Switch с последним обновлением, извлечённые с вашей консоли:
  - **ExeFS** с обновлением: `main`, `main.npdm`, `rtld`, `sdk`, `subsdk0`;
  - **RomFS** с применённым обновлением.
- Linux x86-64 с CPU с AVX2 и GPU с Vulkan 1.3 (Steam Deck подходит), около 60 ГБ свободного места: RomFS, её образ,
  сгенерированный C и объектные файлы.
- Для сборки на SteamOS — `distrobox` (есть в системе) с Ubuntu 26.04.

## Сборка и запуск

Пошагово, с командами для Steam Deck — в [docs/TOTK.md](docs/TOTK.md). Коротко:

1. `tools/gen.py all <exefs> <recomp> --hle runtime/hle/hle_symbols.txt --no-sites` — перевод кода игры в C.
2. Компиляция всех `.c` (zig из AppImage Savage Wind или clang).
3. `make` — рантайм; `tools/link_gamelib.sh <obj> <папка игры>` — библиотека игры `swgame.so`.
4. `build/savagewind --build-romfs <папка игры>` — образ RomFS.
5. `SAVAGEWIND_NO_LAUNCHER=1 build/savagewind <папка игры>` — запуск, лог пишется в терминал.

## Сообщить о проблеме

Создайте issue с логом запуска целиком, моделью CPU/GPU и тем, на каком шаге всё остановилось. Никогда не
прикладывайте файлы игры, ключи, сгенерированный код или сохранения.
